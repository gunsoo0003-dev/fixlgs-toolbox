3\. 도구의 정확한 역할
━━━━━━━━━━━━━━━━━━

이 도구는 변화 전 이미지와 변화 후 이미지 두 장을 하나의 비교용 이미지로 구성하는 도구다.

대표 사용 목적:

- 인테리어 시공 전·후 비교
- 청소 전·후 비교
- 자동차 세차·광택 전후 비교
- 피부·미용 전후 이미지
- 운동·체형 변화 비교
- 사진 보정 전후 비교
- 이미지 압축 전후 비교
- 디자인 수정 전후 비교
- 제품 개선 전후 비교
- 리모델링 전후 비교
- 조경·정비 전후 비교
- 작업 결과 보고 이미지
- 서비스 사례 이미지
- SNS용 Before / After 콘텐츠

대표 작업 흐름:

Before 이미지 선택
→ After 이미지 선택
→ 좌우 또는 상하 비교 선택
→ 두 이미지 크기 자동 맞춤
→ 각 이미지 위치·확대 조절
→ Before·After 문구 설정
→ 중앙 구분선 설정
→ 결과 비율·배경 설정
→ 결과 확인
→ 다운로드

이 도구의 핵심은 두 이미지의 차이를 명확하게 보여주는 비교용 결과물을 만드는 것이다.

단순 이미지 합치기와 구분한다.

5\. 실제 사용자 요구와 반복 문제
━━━━━━━━━━━━━━━━━━

대표 요구:

- 두 사진 크기가 달라도 자동으로 맞추고 싶음
- 좌우 비교와 상하 비교를 쉽게 바꾸고 싶음
- Before와 After 위치를 바로 바꾸고 싶음
- 얼굴이나 물체 위치를 두 사진에서 비슷하게 맞추고 싶음
- 한쪽 사진만 확대하고 싶음
- 사진을 셀 안에서 이동하고 싶음
- Before·After 문구를 다른 글자로 바꾸고 싶음
- 문구를 아예 숨기고 싶음
- 구분선 두께와 색상을 바꾸고 싶음
- 정확한 결과 픽셀 크기를 정하고 싶음
- 로그인이나 워터마크 없이 저장하고 싶음
- 민감한 사진을 서버에 업로드하고 싶지 않음

반복 문제:

- 두 이미지 비율이 다르면 한쪽이 찌그러짐
- 자동 맞춤 과정에서 주요 피사체가 잘림
- 사진 위치를 바꿀 수 없음
- 사진 확대율을 개별 조절할 수 없음
- 좌우를 바꾸면 사진 설정이 초기화됨
- 결과 비율을 바꾸면 피사체 위치가 달라짐
- 중앙 구분선이 실제 중앙과 맞지 않음
- 라벨이 얼굴이나 중요한 내용을 가림
- 라벨 글씨가 배경에 묻힘
- 모바일에서 사진 이동이 어려움
- 미리보기와 실제 다운로드 위치가 다름
- 저장 시 결과가 흐릿함

015는 이러한 문제를 먼저 해결한다.

웹도구 013. 이미지 합치기

- 여러 장

- 순서 변경

웹도구 014. 이미지 콜라주 만들기

담당:

- 2·3·4분할
- 격자
- 다중 이미지 배치

015는 두 장만 사용하며 전후 비교용 라벨과 구분선을 갖는다.

웹도구 016. 이미지에 글자 넣기

- 자유 위치

015의 Before·After 문구는 비교 의미 전달을 위한 제한된 라벨 기능이다.

자유로운 여러 텍스트 객체 편집 기능으로 확장하지 않는다.

담당:

- 텍스트·로고 워터마크

015에는 로고·브랜드 워터마크 기능을 포함하지 않는다.

7\. 핵심 제작 철학
━━━━━━━━━━━━━━━━━━

사용자는 설명 없이 다음 순서를 이해해야 한다.

1. Before 선택

이미지 선택 후 명확해야 할 것:

- 어떤 이미지가 Before인지
- 어떤 이미지가 After인지
- 두 이미지 크기가 어떻게 맞춰지는지
- 사진이 잘리는지 전체가 보이는지
- 라벨과 구분선 설정
- 결과 크기
- 다운로드

7. Before·After 문구를 수정하거나 숨긴다.
8. 중앙 구분선의 두께와 색상을 조절한다.
9. 결과 비율, 크기와 배경을 확인한다.
10. 출력 형식을 선택하고 다운로드한다.

61\. 주의사항
━━━━━━━━━━━━━━━━━━

- 원본 파일은 수정되지 않는다.
- 모든 처리는 현재 브라우저에서 수행된다.
- 채우기 모드에서는 이미지 일부가 비교 영역 밖으로 잘릴 수 있다.
- 전체 보기 모드는 원본 전체를 보여주지만 빈 공간이 생길 수 있다.
- 원본 비율을 강제로 변형하지 않는다.
- 두 이미지의 촬영 각도와 위치가 크게 다르면 완벽하게 일치시키기 어렵다.
- 작은 이미지를 크게 확대하면 결과가 흐려질 수 있다.
- 매우 큰 결과 크기는 브라우저 메모리 부족을 일으킬 수 있다.
- JPG는 투명 배경을 지원하지 않는다.
- 015는 비교 이미지를 제작하는 도구이며 이미지 간 차이를 자동 분석하거나 변화량을 측정하지 않는다.
- 피부·체형 등 전후 이미지는 촬영 조건 차이에 따라 실제 변화와 다르게 보일 수 있으므로 결과의 객관성을 보장하지 않는다.

62\. FAQ

Q1. 사진 두 장의 크기가 달라도 되나요?

예. 각 이미지를 비교 영역에 자동으로 맞추고 위치와 확대율을 별도로 조절할 수 있습니다.

Q2. 좌우뿐 아니라 상하 비교도 가능한가요?

예. 좌우 비교와 상하 비교를 모두 지원합니다.

Q3. 사진이 잘리지 않게 만들 수 있나요?

예. 전체 보기 방식을 사용하면 이미지 전체를 비교 영역 안에 표시할 수 있습니다.

Q4. Before와 After 위치를 바꿀 수 있나요?

예. 한 번에 두 이미지의 위치를 바꿀 수 있습니다.

Q5. Before와 After 글자를 수정할 수 있나요?

예. 각각 원하는 짧은 문구로 변경하거나 라벨을 숨길 수 있습니다.

Q6. 중앙 구분선을 없앨 수 있나요?

예. 구분선을 표시하거나 숨기고 두께와 색상을 조절할 수 있습니다.

Q7. 두 사진의 위치를 따로 조절할 수 있나요?

예. Before와 After 이미지를 각각 이동하고 확대할 수 있습니다.

Q8. 결과 크기를 정할 수 있나요?

예. 결과 비율과 픽셀 크기를 설정할 수 있습니다.

Q9. 투명 배경으로 만들 수 있나요?

예. PNG 또는 투명도를 지원하는 WebP 출력에서 사용할 수 있습니다.

Q10. 이미지는 서버로 전송되나요?

아니요. 현재 브라우저 안에서 처리됩니다.

Q11. 이미지 차이를 자동으로 분석해 주나요?

아니요. 이 도구는 두 이미지를 비교용 레이아웃으로 만드는 도구이며 변화량이나 차이를 자동 판정하지 않습니다.

Q12. 모바일에서도 사진 위치를 맞출 수 있나요?

예. Before와 After를 각각 선택해 위치와 확대율을 조절할 수 있도록 모바일 UI를 최적화합니다.

83\. 최종 제작 명령
━━━━━━━━━━━━━━━━━━

웹도구 015 「전후 비교 이미지 만들기」를 기존 FIXLGS TOOLBOX 프로젝트 구조를 유지한 상태에서 제작한다.

현재 완성된 001\~014 도구와 공통 디자인, 다국어, SEO, 사이트맵, 관련 도구, 파일 처리 구조와 검수기를 실제 코드와 실행 화면에서 확인한 뒤 작업한다.

이미 검증을 통과한 기존 코드와 검수기는 기본적으로 수정하지 않는다.

지원 언어는 한국어·영어·일본어이며 PC·태블릿·모바일과 라이트·다크 모드를 모두 지원한다.

입력은 JPG·JPEG·PNG·WebP 이미지 정확히 두 장을 사용하며 Before 슬롯과 After 슬롯을 명확히 구분한다.

각 슬롯에서 이미지 선택·교체가 가능하고 두 이미지를 한 번에 선택하는 방식도 제공한다.

파일 확장자뿐 아니라 MIME과 실제 디코딩 성공 여부를 확인한다.

핵심 레이아웃은 좌우 비교와 상하 비교다.

좌우 비교의 기본은 Before 왼쪽, After 오른쪽이며 상하 비교의 기본은 Before 위, After 아래다.

기본 분할 비율은 50:50이고 중앙 구분선을 표시한다.

안전하게 구현 가능하면 분할 비율을 조정할 수 있도록 하되 중앙 복귀 기능을 반드시 제공한다.

Before와 After 이미지는 원본 비율을 강제로 변형하지 않는다.

각 이미지 영역에 대해 Cover와 Contain 두 가지 맞춤 방식을 제공한다.

Cover는 영역 전체를 채우되 일부 이미지가 보이지 않을 수 있고, Contain은 원본 전체를 보여주되 빈 공간이 생길 수 있다.

각 이미지는 독립적으로 위치를 이동하고 확대·축소할 수 있어야 하며, 프레이밍을 잘못 맞춘 경우 해당 이미지의 위치·확대를 초기화할 수 있어야 한다.

Before와 After의 자리 바꾸기 기능을 제공하며 이미지와 연결된 fitMode, 확대율, 위치와 사용자 입력 라벨 의미도 함께 안전하게 이동한다.

Before·After 라벨은 기본 표시하되 사용자가 각각 문구를 수정하거나 라벨 전체를 숨길 수 있게 한다.

라벨에는 위치, 글자 크기, 글자 색상, 배경색과 배경 투명도를 제공한다.

015의 라벨은 비교 의미 전달을 위한 두 개의 제한된 텍스트 요소이며 자유 텍스트 디자인 도구로 확장하지 않는다.

중앙 구분선은 표시·숨김, 두께, 색상과 중앙 복귀를 제공한다.

좌우에서는 세로선, 상하에서는 가로선으로 정확하게 렌더링한다.

구분선의 픽셀 위치와 두께 때문에 선이 흐릿해지지 않도록 최종 출력 픽셀 정렬을 검수한다.

결과에는 1:1, 4:5, 5:4, 3:2, 2:3, 16:9, 9:16과 사용자 지정 비율을 제공하는 방향을 기본으로 하고 결과 너비·높이를 표시한다.

이미지 사이 간격, 전체 동일 외곽 여백, 단색·투명 배경을 제공한다.

상하좌우 개별 여백, 자유 텍스트 객체, 로고, 워터마크, 스티커, 도형, 그림자, 둥근 모서리, 이미지 3장 이상 비교, 콜라주, 파노라마, Interactive Slider 결과, 동영상·GIF 출력, AI 이미지 정렬, 자동 차이 분석과 변화량 측정은 015에 포함하지 않는다.

두 원본의 크기와 비율이 크게 달라도 각 비교 영역에서 비율을 유지하고 사용자가 직접 주요 피사체 위치를 조정할 수 있게 한다.

한쪽 원본 해상도가 매우 낮아 결과 영역에서 확대될 경우 화질 저하 가능성을 안내한다.

미리보기와 최종 결과는 동일한 비교 레이아웃·좌표 모델을 사용하고 CSS로 대략적인 결과를 별도로 만든 뒤 최종 Canvas에서 다른 계산을 사용하는 구조를 피한다.

라벨·구분선·이미지 위치까지 실제 다운로드 결과와 미리보기가 동일해야 한다.

미리보기에서는 축소 이미지를 사용하고 이미지 위치 변경과 확대 중에는 requestAnimationFrame 등을 사용해 부드럽게 반응하도록 한다.

최종 다운로드 시 원본 이미지와 최종 좌표를 기준으로 JPG·PNG·WebP 결과를 렌더링한다.

PNG와 투명 WebP는 투명 배경을 유지하고 JPG 선택 시 투명 영역에 적용할 배경색을 명확히 처리한다.

사용자가 레이아웃·이미지 위치·라벨을 빠르게 변경하거나 이미지 교체를 수행할 때 오래된 비동기 렌더링 완료가 최신 상태를 덮어쓰지 않게 render revision 또는 동등한 상태 보호 구조를 사용한다.

이미지 교체, 전체 초기화와 결과 재생성 시 Object URL, ImageBitmap, Canvas, 결과 Blob과 Worker를 안전하게 정리한다.

PC·모바일 실제 부하 검수를 통해 입력 이미지와 결과 Canvas의 안전 한계를 확정하며 결과가 크다는 이유로 사용자 모르게 출력 해상도를 낮추지 않는다.

TOOLBOX 공통 디자인인 화이트·블랙·산토리니 블루 1색과 절제된 고급감을 유지한다.

PC에서는 비교 미리보기를 가장 크게 보여주고 이미지 맞춤, 라벨, 구분선, 결과 설정을 구분한다.

모바일에서는 비교 미리보기를 우선 배치하고 Before·After 탭을 통해 각각의 사진 위치와 확대율을 조정할 수 있게 한다.

필요하면 선택 이미지를 크게 볼 수 있는 모바일 편집 모드를 제공하여 작은 좌우 비교 영역에서도 정확하게 프레이밍할 수 있게 한다.

한국어·영어·일본어 UI, 일본어 모바일 줄바꿈, 언어 전환 시 같은 015 페이지 유지, 언어별 URL, H1, 메타 제목, 메타 설명, canonical, hreflang, x-default, WebApplication, FAQPage, BreadcrumbList, sitemap과 robots를 적용한다.

기존 app/sitemap.ts와 app/robots.ts 구조를 유지하고 015의 한국어·영어·일본어 URL만 안전하게 추가한다.

광고는 Before·After 이미지 선택, 비교 미리보기, 사진 위치·확대, 라벨, 구분선, 결과 설정, 결과 생성과 다운로드 주변에 배치하지 않는다.

공통 자동 검수와 015 전용 검수를 준비하여 Before·After 슬롯, 자리 바꾸기, 좌우·상하 좌표, Cover·Contain, 개별 pan·zoom, split 위치, 라벨 렌더링, divider, 결과 비율, 배경, 투명도, JPG·PNG·WebP 출력, 비동기 최신 상태 보호와 메모리 정리를 검증한다.

작업 완료 전 기능 축소 여부, 기준 디자인 실제 이식 여부, 기존 검증 기능 영향 여부와 완료라고 말할 실제 근거가 있는지를 확인하는 4대 검증을 수행한다.

자동 검수, 수동 화면 검수, 서로 다른 비율·해상도 이미지 검수, 모바일 이미지 위치 조정 검수, 실제 다운로드 결과 검수, 이전 도구 회귀 검수, 빌드, 배포, Search Console URL 검사와 한국어·영어·일본어 URL 색인 요청까지 완료한 뒤에만 웹도구 015를 도장깨기 완료로 처리한다.

불명확한 사항은 임의로 결정하지 않고 실제 프로젝트 코드와 기존 확정 기준을 우선한다.

사용자가 서로 다른 크기와 비율의 Before·After 이미지 두 장을 업로드한 뒤 좌우 또는 상하 비교 레이아웃에 정확하게 배치하고, 각 이미지의 위치와 확대율을 직접 맞추며, Before·After 문구와 중앙 구분선을 조정해 깔끔한 비교 이미지를 고품질로 다운로드할 수 있는 브라우저 기반 전후 비교 이미지 제작 도구를 완성한다.

두 이미지를 단순히 절반씩 이어 붙이는 수준에서 끝내지 않는다.

서로 다른 비율의 사진도 왜곡 없이 맞출 수 있고, 주요 피사체 위치를 각각 조절할 수 있으며, 라벨·구분선·결과 비율·투명도·모바일 편집과 실제 다운로드까지 안정적으로 작동하는 완성도 높은 비교 이미지 도구를 제작한다.
