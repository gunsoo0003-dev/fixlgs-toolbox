TOOL001 MOBILE WORKFLOW VALIDATOR V17

목적
- 실기기 테스트 이전 자동검수 단계에서 모바일 작업흐름의 관찰 가능한 실패를 최대한 선제 검출한다.
- 실기기 테스트는 이 검수에 포함하지 않는다. 배포 후 최종 마지막 단계에서 별도 수행한다.

정상 작업흐름 필수 게이트
01 초기 파란 업로드 영역 표시
02 실제 picker/change 이벤트 발생
03 파일 수락 후 파란 업로드 영역 제거 + active 영역 전환
04 파일 카드/파일명/실제 dimensions 생성
05 preview img 실제 decode 완료(naturalWidth/Height > 0)
06 모바일 가로 overflow/화면 밖 이탈 없음
07 후속 변환 버튼 표시/활성/pointer-events/z-index 차단 없음
08 변환 terminal state=done
09 실제 다운로드 이벤트 + 정상 확장자
10 window.error/unhandledrejection 0
11 전체 초기화 후 초기 상태 복귀
12 동일 파일 재선택 후 다시 상태 전환

원인 계층
- picker/tap/overlay/z-index/pointer-events
- input change/FileList 캡처/async clear timing
- 빈 파일/MIME alias·blank·octet-stream/확장자·대소문자·유니코드·무확장
- signature/mismatch/trailing bytes/EOI
- arrayBuffer 실패/지연/파일 reference lifetime/input clear/remove/focus/visibility
- createImageBitmap missing/throw/delay/objectURL fallback
- objectURL/revoke/randomUUID
- state commit/items 전환/파란영역 제거/active 영역/card 생성
- preview decode/natural dimensions
- 모바일 horizontal overflow/화면 밖 이탈
- 후속 control visibility/enabled/overlay 차단
- conversion terminal state/resultBlob
- individual download
- runtime error/unhandled rejection
- reset/reselect/concurrency/multi-file
- MAX_FILES/MAX_FILE_BYTES/MAX_TOTAL_BYTES/MAX_PIXELS
