TOOL001 REAL DEVICE NOTREADABLE PYRAMID V35

목적
- V33에서 확정된 직접 실패: provider File 실제 read -> NotReadableError
- V35는 NotReadableError의 상위 원인을 피라미드 1단계에서 8개 큰 카테고리로 압축
- 검수기는 원인을 만들지 않고 실제 사용자 행동을 재현하면서 증거만 관찰

구조
- 8개 카테고리 × 각 3회 = 24회/세트
- 동일 검수 2세트 = 총 48회
- 성공은 카드+실제 미리보기 생성 즉시 PASS
- 실패는 최대 약 6.5초 후 FAIL 후 다음 케이스
- HARNESS 오류는 제품 FAIL과 분리

카테고리
C01 PHOTO_01 Provider/URI 수명·권한
C02 PHOTO_02 Input/DOM 수명
C03 PHOTO_03 중복·동시 read
C04 PHOTO_04 Photo Picker 복귀/read 타이밍
C05 PHOTO_05 React lifecycle/DOM 교체
C06 PHOTO_06 이전 작업/abort 잔존
C07 PHOTO_07 Chrome/Android File 처리
C08 PHOTO_08 선행 validation/decode 접근

판정
- 두 세트 모두 실패 관찰: STRONG_BRANCH -> 다음 피라미드 하위 진단
- 한 세트만 실패: SUSPECT_BRANCH -> 추가 반복
- 6/6 성공: CLEAN_6_OF_6_CONFIRM_LATER -> 별도 10회 검증 후 제외 가능
