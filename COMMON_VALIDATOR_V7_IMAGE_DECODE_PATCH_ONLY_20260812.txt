FIXLGS TOOLBOX COMMON VALIDATOR V7 - IMAGE DECODE HARDENING
Date: 2026-08-12

Scope
- Validator/test harness only.
- No product page/component/CSS code changed.

Added validation chain after actual file chooser selection:
1. File.name present
2. File.size > 0
3. URL.createObjectURL(file) succeeds
4. Image.onload fires
5. Image.onerror does not fire
6. naturalWidth > 0
7. naturalHeight > 0
8. IMAGE_DECODE_PASS emitted in test log

Applied to
- FULL desktop upload
- FULL mobile browser upload
- FAST representative desktop/mobile upload
- non-optimized common-user-path spec (kept in sync)

Important verdict semantics
- MOBILE_BROWSER_PATH_PASS: Playwright mobile-emulated browser path including File -> objectURL -> Image decode -> natural dimensions passed.
- REAL_DEVICE_NOT_VERIFIED: no physical Android/iOS device verification performed.
- REAL_DEVICE_PASS: must only be used after physical-device verification.

Limitation
- Playwright setFiles() does not reproduce Android/iOS system file-provider behavior exactly.
- Therefore V7 closes the previous "change event only" coverage hole, but it must not be treated as REAL_DEVICE_PASS.
