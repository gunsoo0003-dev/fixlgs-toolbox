INTERPRETATION
- CHANGE PASS / FILE FAIL: product handler did not acquire selected File.
- FILE PASS / READ_START FAIL: capture path was not entered.
- READ_START PASS / SNAPSHOT FAIL: provider read/capture failure; inspect reader-fail and capture-bytes-fail.
- SNAPSHOT PASS / STATE_PREVIEW FAIL: app-owned snapshot succeeded; inspect product inspection/state/preview path.
- ALL PASS: continue conversion/result/ZIP validation.
