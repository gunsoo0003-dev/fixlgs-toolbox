TOOL001 MOBILE V56 — DIRECT DECODE FIRST (2026-08-13)

목표
- V55에서 남아 있던 선행 inspectImageFile() 경로를 제거한다.
- 선택 직후 provider-backed File에 대해 JS arrayBuffer/FileReader/stream/header sniff를 먼저 실행하지 않는다.

V56 최초 경로
[input type=file]
→ selected File
→ browser image decoder (createImageBitmap 우선, blob URL + <img> fallback)
→ decoded pixels
→ Canvas snapshot
→ app-owned File
→ 이후 preview / conversion은 app-owned File만 사용

초기 단계에서 제거된 것
- inspectImageFile(selectedFile)
- readAttachHeader()
- slice().arrayBuffer()
- FileReader header fallback
- signature sniff
- showOpenFilePicker / FileSystemHandle 경로 (V55에서 이미 제거)
- provider read retry

주의
- 이 버전은 Android Chrome NotReadable/ERR_UPLOAD_FILE_CHANGED 원인 분리를 위한 제품 실험본이다.
- 최초 decode 성공 후에는 앱 소유 snapshot으로 분리한다.
- 기존 UI와 변환/다운로드 흐름은 유지한다.
