# Third-party notices

The image compressor loads the following pinned browser-side modules only when PNG compression is requested. User image files are not uploaded to these module providers; the modules execute in the user's browser.

- `@jsquash/oxipng@2.3.0` — Apache License 2.0. Browser/WebAssembly PNG optimization derived from OxiPNG and Squoosh.
- `image-q@4.0.0` — MIT License. Browser-side color quantization with alpha support.

The original license and copyright notices for these projects remain available from their respective distributions and repositories.
