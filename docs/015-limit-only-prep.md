# 015 보수적 서비스 유효상한 후보 + limit-only 준비

도구: 웹도구 015 전후 비교 이미지 만들기
route: `/ko|en|ja/before-after-image-maker`

## 확정 계약
- 입력 슬롯: 정확히 2개(Before / After)
- 3장 이상 동시 선택 시 첫 2장만 몰래 사용하지 않고 명확히 거부

## 보수적 서비스 유효상한 후보
- 개별 파일 크기: 15 MiB / 확신도 보통
- 두 파일 총 용량: 30 MiB / 확신도 보통
- 원본 한 장 해상도: 24 MP / 확신도 보통
- 결과 최대 한 변: 3000 px / 확신도 높음
- 결과 총 픽셀: 9 MP / 확신도 보통
- 짧은 비교 라벨 권장 상한 후보: 24자 / 확신도 보통

선정 이유: 일반 스마트폰 사진 2장을 전후 비교하는 목적에는 충분하고, 저사양 모바일·다중 탭 환경에서 두 원본 Bitmap + 미리보기 + 결과 Canvas + Blob을 동시에 유지할 때 안전마진을 확보하기 위함이다. 24MP 초과 초고해상도 원본, 3000px/9MP 초과 출력, 초대형 파일은 전문·하드코어 영역으로 기본 후보에서 제외한다.

후보는 최종 제품 제한값이 아니다. 주작업장이 최신 통합본에서 검수 후 낮추거나 높일 수 있다.

## 조정 위치
`tests/config/tool-015-limit-candidates.ts`

## 기본 자동 probe
- 2장 정상
- 3장 명시적 거부
- 출력 한 변 2999 / 3000 / 3001

고부하 파일 크기·24MP 실제 샘플 생성은 보조작업장에서 파괴 탐색하지 않는다.


[출고 보완 4항목 반영]
- 제품 코드의 임시 16384px / 100MP 하드 차단값 제거: 최종 서비스 한계 확정 전 후보값을 제품 제한으로 오인하지 않도록 함.
- limit-only 준비 확장: 개별 파일 15MiB, 총 30MiB, 원본 24MP 후보를 실제 유효 PNG fixture로 생성해 후보 단계에서 바로 검수 가능.
- preflight 실행기도 기존 결과 규칙에 맞춰 결과 ZIP 생성 연결.
- regression-only는 기존 001~014 KO/EN/JA route 보호 및 015 관련 도구 링크(013/014/004/006) 연결까지 검사.
