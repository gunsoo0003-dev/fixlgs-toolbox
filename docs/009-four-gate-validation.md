# 웹도구 009 완료 전 4대 검증 기록

## 1. 간단한 1차 수준으로 축소됐는가
- 판정: 코드 구현 기준 통과
- 확인 파일: `components/image-brightness-color-adjuster-tool.tsx`, `components/image-brightness-color-adjuster-page.tsx`
- 구현 확인: 밝기, 대비, 채도, 색온도, Unsharp Mask 선명도, 흑백, 세피아, 로컬 분석 자동보정, 실시간 미리보기, 원본/결과/비교, 확대/축소/화면 맞춤, 직접 숫자 입력, 실행 취소/다시 실행, 개별 초기화, 모든 보정값 초기화, 전체 초기화, JPG/PNG/WebP 출력, 품질, 파일명, JPG 투명 배경색, 결과 정보
- 보완 확인: MIME·확장자 불일치 차단, 실제 디코딩 검증, 처리 중 교체·초기화 토큰 취소, Object URL·ImageBitmap 정리, 미지원 형식 관련 도구 연결
- 확정 제외: 다중 이미지 일괄 보정과 전달서의 제외 기능
- 남은 문제: 실제 실행 환경에서 자동검수와 부하검수 실행 필요

## 2. 기준 디자인을 실제로 이식했는가
- 판정: 코드 구조 기준 통과, 실제 화면 최종 판정 대기
- 기준 도구: 006 사용 방법 구분선, 007 비교 구조, 008 이미지 편집 페이지 구조
- 이식 구조: 공통 헤더·영웅 영역·작업 카드·다음 작업·사용 방법·전문 콘텐츠·FAQ·푸터 유지
- 007·008·009 사용 방법: 006과 동일한 구분선 구조 적용
- PC: 큰 미리보기 + 우측 설정 패널
- 태블릿: 단일 미리보기 + 2열 설정 패널
- 모바일: 미리보기→비교→설정→출력→다운로드 세로 흐름
- 일본어/다크: 전용 CSS와 자동검수 항목 추가
- 남은 문제: 실제 Chromium 캡처 비교 필요

## 3. 기존 검증 기능을 망가뜨리지 않았는가
- 판정: 변경 범위 기준 통과, 실행 회귀검수 대기
- 기존 001~008 기능 엔진과 검수기는 수정하지 않음
- 공통 변경: `app/globals.css`의 007·008·009 사용 방법 구분선 및 009 전용 스타일
- 사이트맵·라우팅·카테고리에는 009 항목만 추가
- 기존 URL을 삭제하거나 교체하지 않음
- 확인 명령: `npm run test:toolbox:009-final`

## 4. 완료라고 말할 근거가 있는가
- 판정: 구현본 수준 완료 / 실행 완료 판정은 보류
- 코드·다국어·SEO·구조화 데이터·사이트맵·카테고리·검수기·통합 실행기 준비 완료
- 자동검수 범위: 3개 언어, SEO, 필수 컨트롤, 효과 상호 배타, 투명 JPG 경고, 오류, 초기화 구분, 비교 키보드, 일본어 모바일 넘침, 픽셀 경계, MIME 불일치
- 현재 환경 제약: 내부 npm 저장소에 `@playwright/test`가 없어 의존성 설치, Next.js 빌드, Playwright 실행 불가
- 최종 완료 조건: 사용자 PC에서 통합검수 0 실패, 실제 PC·태블릿·모바일·다크·일본어 화면 확인, 안전 한도 결과 반영, 배포·색인 요청
