# TOOL 029 모바일 실기기 검수 등록 준비

실제 스마트폰 실테스트는 PDF 카테고리 완료 후 카테고리 단위 실행 정책을 따른다. 다만 TOOL 029은 글로벌 모바일 runner 대상 등록이 필요하다.

주작업장 이식 후 runner에 추가할 사용자 경로:
1. `/ko/split-extract-pdf` 진입
2. 실제 10페이지 PDF 선택
3. 업로드 후 총 페이지/썸네일 확인
4. 특정 페이지 추출 → 1,3,5-8
5. 썸네일 2번 선택/해제
6. 범위 분할 → 1-3 / 4-7 / 8-10
7. 홀수+짝수 예상 결과 2개 확인
8. 페이지별 개별 PDF 예상 결과 10개 확인
9. 실제 처리 후 결과/ZIP 다운로드
10. 초기화/새 PDF 복구

모바일 viewport 자동검수:
- 모드 카드 1열 전환
- 설정/썸네일 세로 배치
- 썸네일 2열
- 긴 일본어 버튼 가로 overflow 없음
- 범위 입력/실행 버튼 가림 없음

최신 028 배포완료 기준의 글로벌 모바일 runner를 001~029로 확장했고 TOOL029 route/input/success/result/download 판정을 등록했다. 실제 스마트폰 실행은 PDF 카테고리 종료 시 일괄한다.
