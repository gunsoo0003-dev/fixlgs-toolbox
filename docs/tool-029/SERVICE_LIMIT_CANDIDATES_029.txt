TOOL 029 FINAL SERVICE LIMITS
상태: 최종 확정

- 입력 PDF: 1개
- 파일당: 50 MiB
- 총 페이지: 300
- 생성 결과 파일: 최대 300
- 범위 항목: 최대 100

확정 근거
- Adobe Acrobat Online Split PDF 공개 한도는 최대 1GB / 1,500페이지 수준이지만 서버 기반 서비스다.
- FIXLGS TOOL029는 브라우저 로컬 처리이므로 일반 PC·노트북·모바일 브라우저 안정성을 우선해 입력 용량은 50 MiB로 보수적으로 제한한다.
- 페이지/출력/범위는 실제 사용성과 개별 페이지 추출 기능을 고려해 300페이지 / 300결과 / 100범위로 확정한다.
- 제품 정책, UI 문구, fixture, limit spec, source checker는 동일 값으로 동기화한다.
