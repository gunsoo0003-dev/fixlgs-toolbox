# 009 이미지 밝기·색상 보정기 검수 기준

- 단일 JPG/JPEG/PNG/WebP 입력, MIME 및 실제 디코딩 검증
- 밝기·대비·채도·색온도·Unsharp Mask 선명도 픽셀 처리
- 흑백·세피아 상호 배타 처리
- 로컬 히스토그램/채널 평균 기반 자동보정
- 축소 미리보기와 원본 해상도 최종 렌더링 분리
- 원본/결과/Before-After 비교, Undo/Redo, 개별·전체 보정 초기화
- JPG/PNG/WebP 출력, 품질 및 안전한 파일명
- 한 장, 24MP 이하, 한 변 16,384px 임시 안전선
- 한국어·영어·일본어, 모바일·PC, 라이트·다크, SEO·sitemap 회귀

현재 안전선은 최종 자동 한계탐색 전의 보수적 기준이다. 실제 PC·모바일 한계탐색 결과에 따라 코드·안내·검수기를 함께 조정한다.
