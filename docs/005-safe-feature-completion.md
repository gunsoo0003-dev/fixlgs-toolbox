# 005 안전 기능 보강

## 추가 구현

- JPG EXIF 방향 직접 판독 및 결과 픽셀 방향 정상화
- 브라우저가 EXIF 방향을 이미 적용한 경우 중복 회전 방지
- 파일별 최소 품질 설정
- 파일별 최소 이미지 크기 설정
- 파일별 크기 축소 허용 설정
- 품질 탐색·크기 축소 단계별 진행률과 상태 문구
- 처리 중 설정 변경·파일 추가 차단
- 처리 중 전체 초기화 시 즉시 데이터 삭제 대신 안전 취소 요청
- 설정 변경 시 이전 결과 Blob·Object URL 정리
- 목표 미달성 원인 구분: 근접 초과·최소 품질·최소 크기
- 목표 미달성 결과는 사용자 명시 선택 후에만 다운로드/ZIP 포함
- 목표 미달성 시 크기 축소 허용 후 재시도 동선
- 접근성 라벨 보강
- 005 기능 자동검수 추가

## 안전상 제외 유지

- 메타데이터 유지: 형식별 보존 편차와 개인정보 위험 때문에 기본 제거만 유지
- Web Worker: WASM·브라우저별 안정성 검증 전까지 순차 처리 유지
- 자동 형식 변환: 005 역할과 불일치
- 서버 업로드·유료 API: 사용하지 않음

## 검수 추가 항목

- EXIF 회전 JPG 결과 크기
- 파일별 최소 품질·최소 크기 독립 설정
- 설정 변경 시 이전 결과 제거
- 목표 미달성 결과의 명시적 사용 승인
