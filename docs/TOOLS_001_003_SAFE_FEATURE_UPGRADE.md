# TOOLBOX 001~003 안전 기능 보강

## 001 JPG·PNG·WebP 이미지 변환기
- 실제 파일 시그니처와 확장자 일치 확인
- APNG 및 애니메이션 WebP 선택 차단
- 동일 파일 중복 추가 방지
- 파일 수·개별 용량·전체 용량·픽셀 안전 제한
- EXIF 방향을 반영하는 브라우저 디코딩 우선 사용
- 손상·형식 불일치·제한 초과 파일만 제외하고 나머지는 계속 처리

## 002 HEIC·AVIF 이미지 변환기
- 실제 파일 형식과 확장자 일치 확인
- 동일 파일 중복 추가 방지
- 파일 순서 위·아래 이동
- 실패 파일 개별 재시도
- 전체 초기화 시 품질·배경색·고급 설정까지 복원

## 003 SVG·BMP·TIFF 이미지 변환기
- SVG·BMP·TIFF 실제 파일 시그니처 확인
- BigTIFF를 일반 TIFF로 오인하지 않고 제외
- 동일 파일 중복 추가 방지
- BMP 선택 단계에서 실제 디코딩·픽셀 제한 확인
- 파일 순서 위·아래 이동
- 실패 파일 개별 재시도
- TIFF 페이지를 하나도 선택하지 않은 경우 전체 변환으로 되돌리지 않고 명확히 안내

모든 보강 기능은 브라우저 내부 처리이며 별도 유료 API·서버 저장·로그인이 필요하지 않습니다.
