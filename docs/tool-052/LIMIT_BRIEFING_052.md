# TOOL052 SERVICE LIMIT BRIEFING

- 선택 도시: 최대 12개
- 최소 비교 도시: 2개
- 회의시간 계산 도시: 선택 도시와 동일, 최대 12개
- 업무시간: 도시별 1개 구간, 기본 09:00-18:00
- 회의 탐색 간격: 30분
- 날짜 입력: 1900-01-01 ~ 2100-12-31
- 도시 검색 결과 UI: 최대 12개 후보를 즉시 표시
- 도시 index: 1차 대표 도시 중심 34개

근거: 제작전달서가 최대 12개를 보수적 서비스 상한으로 고정하고, 전체 수만 개 도시 bundle은 차기 확장으로 분리함.
