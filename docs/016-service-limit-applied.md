# TOOLBOX 016 서비스 유효상한 적용

016 이미지에 글자 넣기의 기본 대상은 일반 PC·노트북·스마트폰·브라우저의 일반 사용자와 중간 수준 라이트 사용자다.
기술적 최대치가 아니라 단일 사진에 여러 문구를 넣는 실제 사용 흐름과 모바일 메모리 부담을 기준으로 주작업장에서 다음 값을 최종 서비스 상한으로 확정한다.

- 입력 이미지: 1장
- 파일당 최대: 15 MiB
- 이미지 총 픽셀: 최대 12,000,000 px
- 이미지 한 변: 최대 6,000 px
- 텍스트 레이어: 최대 20개
- 레이어당 문자: 최대 2,000자
- 실행 취소 히스토리: 최대 30단계
- 출력 크기: 입력 원본 해상도와 동일하므로 위 이미지 픽셀/한 변 상한을 그대로 적용

선정 이유:
12MP·6,000px는 일반 스마트폰·카메라 사진 편집에 충분하면서 원본 해상도 Canvas, 미리보기 Canvas, 출력 Canvas와 텍스트 효과가 동시에 사용하는 메모리를 보수적으로 제한한다.
20개 레이어와 레이어당 2,000자는 제목·본문·날짜·위치·설명 등 일반 사진 편집 흐름에는 충분하며, 그 이상은 전문 레이어 편집 또는 문서 편집 영역에 가깝다.
30단계 Undo는 일반 편집의 복구 범위를 충분히 제공하면서 레이어 상태 스냅샷 누적을 제한한다.

전문 영역으로 제외:
수백 레이어, 수천 줄 문서 편집, 12MP·6,000px를 크게 넘는 초고해상도 전문 인쇄 원본, 사용자 폰트 업로드, 복잡한 transform, 다중 이미지 일괄 텍스트 적용.

limit-only는 위 값의 한도 직전 / 정확한 한도 / 한도 초과를 실제 기능 코드 기준으로 검증한다.
