3\. 도구의 정확한 역할
━━━━━━━━━━━━━━━━━━

이 도구는 여러 장의 이미지를 미리 정의된 2차원 레이아웃의 여러 칸에 배치하여 하나의 콜라주 이미지로 만드는 도구다.

대표 사용 목적:

- 사진 2장을 한 이미지에 배치
- 사진 3장을 균형 있게 배치
- 사진 4장을 2×2로 배치
- 여러 사진을 격자형으로 정리
- 제품 사진 여러 장을 한 이미지로 구성
- 여행 사진 묶음 만들기
- SNS 게시용 사진 모음 만들기
- 블로그 대표 이미지 구성
- 전·중·후 과정 사진을 한 화면에 정리
- 서로 다른 비율 사진을 같은 셀 안에 자연스럽게 맞추기
- 사진 사이에 여백과 테두리를 넣어 카드형 이미지 만들기
- 배경색이 있는 깔끔한 콜라주 만들기

대표 작업 흐름:

이미지 여러 장 선택
→ 사진 수에 맞는 레이아웃 선택
→ 각 셀에 이미지 배치
→ 셀별 이미지 위치·확대 조정
→ 간격·테두리·배경 조정
→ 결과 확인
→ 다운로드

013이 한 줄로 이미지를 이어 붙이는 도구라면 014는 여러 칸을 가진 2차원 레이아웃에 이미지를 배치하는 도구다.

TOOLBOX 014에서는 지나치게 많은 디자인 템플릿을 제공하지 않는다.

목표는 Canva나 전문 디자인 프로그램을 만드는 것이 아니라:

"사진 여러 장을 원하는 격자로 빠르게 정리하는 도구"

다.

따라서 템플릿 수보다 다음을 우선한다.

- 기본 레이아웃 이해 속도
- 원본 비율 처리
- 셀별 사진 위치 수정
- 모바일 조작성
- 정확한 결과 크기
- 로컬 처리
- 고화질 출력

5\. 실제 사용자 문제를 반영한 제작 원칙
━━━━━━━━━━━━━━━━━━

콜라주 도구에서 특히 피해야 할 문제:

- 템플릿 비율에 맞추기 위해 사진이 과도하게 잘림
- 사진 얼굴이나 주요 피사체가 셀 밖으로 잘림
- 셀 안에서 위치를 수정할 수 없음
- 서로 다른 비율 사진이 강제로 찌그러짐
- 작은 이미지가 지나치게 확대되어 흐려짐
- 이미지 순서를 바꾸기 어려움
- 레이아웃을 바꾸면 사진 설정이 전부 초기화됨
- 모바일에서 셀을 선택하기 어려움
- 사진을 드래그하려다 페이지가 스크롤됨
- 여백과 테두리의 의미가 불명확함
- 다운로드 결과와 미리보기가 다름
- 결과 픽셀 크기를 알 수 없음
- PNG 투명 배경이 손실됨

014는 이러한 문제를 우선 제거한다.

- 확대·축소
- 이미지 교체

- 레이아웃
- 결과 비율
- 간격
- 외곽 여백
- 테두리
- 배경색

셀별 설정:

- 이미지
- 맞춤 방식
- 위치
- 확대율

전체 설정과 셀 설정을 명확히 구분한다.

12\. 최종 기능 범위

필수:

- 개별 이미지 삭제

레이아웃:

- 2분할
- 3분할
- 4분할
- 기본 격자형

2분할:

- 좌우 1:1
- 상하 1:1

3분할:

- 3열
- 3행
- 큰 1 + 작은 2 세로형
- 큰 1 + 작은 2 가로형

4분할:

- 2×2
- 4열
- 4행
- 큰 1 + 작은 3 형태는 안정적 구현 시 추가

격자:

- 2×2
- 2×3
- 3×2
- 3×3

도장깨기 기본 2·3·4분할을 먼저 완성하고 격자형을 추가한다.

레이아웃 수를 무분별하게 늘리지 않는다.

56\. 주의사항
━━━━━━━━━━━━━━━━━━

- 원본 파일은 수정되지 않는다.
- 모든 처리는 브라우저에서 수행된다.
- 채우기 모드에서는 셀 비율에 따라 사진 일부가 보이지 않을 수 있다.
- 전체 보기 모드를 선택하면 원본 전체가 표시되지만 셀 안에 빈 공간이 생길 수 있다.
- 이미지 비율을 강제로 변형하지 않는다.
- 이미지를 과도하게 확대하면 화질이 낮아질 수 있다.
- 매우 큰 출력 크기는 모바일 브라우저에서 메모리 부족을 일으킬 수 있다.
- PNG는 JPG보다 결과 용량이 커질 수 있다.
- JPG는 투명 배경을 지원하지 않는다.
- 콜라주 레이아웃 변경 시 셀 위치가 다시 계산될 수 있다.
- 014는 여러 이미지를 격자에 배치하는 도구이며 파노라마·자유 레이어 디자인 도구가 아니다.

57\. FAQ
━━━━━━━━━━━━━━━━━━

Q1. 사진 몇 장으로 콜라주를 만들 수 있나요?

기본적으로 2·3·4분할과 최대 3×3 격자 레이아웃을 제공합니다.

Q2. 사진 비율이 서로 달라도 되나요?

예. 각 셀에서 채우기 또는 전체 보기 방식을 선택할 수 있습니다.

Q3. 사진이 잘리지 않게 할 수 있나요?

예. 전체 보기를 선택하면 원본 이미지 전체를 셀 안에 표시합니다.

Q4. 사진 위치를 바꿀 수 있나요?

예. 선택한 셀 안에서 사진을 드래그해 보이는 위치를 조절할 수 있습니다.

Q5. 사진을 확대할 수 있나요?

예. 셀별로 이미지 확대율을 조절할 수 있습니다.

Q6. 사진 순서를 바꿀 수 있나요?

예. 이미지 목록의 순서와 셀의 이미지를 변경하거나 교환할 수 있습니다.

Q7. 이미지 사이 간격을 조절할 수 있나요?

예. 이미지 사이 간격과 전체 외곽 여백을 각각 설정할 수 있습니다.

Q8. 테두리를 추가할 수 있나요?

예. 콜라주 셀을 구분하는 테두리의 두께와 색상을 설정할 수 있습니다.

Q9. 투명 배경도 가능한가요?

예. PNG 또는 투명도를 지원하는 WebP 출력에서 사용할 수 있습니다.

Q10. 이미지는 서버에 업로드되나요?

아니요. 현재 브라우저 안에서 처리됩니다.

Q11. 모바일에서도 사진 위치를 바꿀 수 있나요?

78\. 최종 제작 명령
━━━━━━━━━━━━━━━━━━

웹도구 014 「이미지 콜라주 만들기」를 기존 FIXLGS TOOLBOX 프로젝트 구조를 유지한 상태에서 제작한다.

현재 완성된 001\~013 도구와 공통 디자인, 다국어, SEO, 사이트맵, 관련 도구, 다중 이미지 처리 구조와 검수기를 실제 코드와 실행 화면에서 확인한 뒤 작업한다.

기존 검증 완료 코드와 검수기는 기본적으로 수정하지 않는다.

지원 언어는 한국어·영어·일본어이며 PC·태블릿·모바일과 라이트·다크 모드를 모두 지원한다.

입력은 JPG·JPEG·PNG·WebP 여러 장을 지원하며 파일 선택, 드래그 앤 드롭, 이미지 추가, 개별 삭제와 셀별 이미지 교체를 제공한다.

핵심 레이아웃은 2분할, 3분할, 4분할과 격자형이다.

2분할은 최소 좌우·상하, 3분할은 3열·3행과 큰 1칸+작은 2칸 형태, 4분할은 2×2·4열·4행, 격자는 2×2·2×3·3×2·3×3까지 제공하는 방향을 기본으로 한다.

레이아웃 수를 지나치게 늘려 전문 디자인 템플릿 서비스로 확장하지 않는다.

각 셀에는 이미지를 자동 배치하되 사용자가 직접 이미지 교체, 셀 간 교환, 위치 이동, 확대·축소와 맞춤 방식을 변경할 수 있어야 한다.

셀 이미지 맞춤은 최소 Cover와 Contain 두 방식을 제공한다.

Cover는 셀을 모두 채우면서 원본 비율을 유지하고 일부가 잘릴 수 있으며, Contain은 원본 전체를 표시하면서 남는 영역에는 콜라주 배경을 표시한다.

이미지 비율을 강제로 변형해 찌그러뜨리지 않는다.

Cover 모드에서는 이미지를 셀 안에서 드래그하여 주요 피사체의 위치를 조정할 수 있어야 하며 확대율도 조절할 수 있어야 한다.

레이아웃을 변경하거나 결과 비율을 변경하더라도 업로드한 파일을 제거하지 않고, 셀 이미지 연결과 사용자의 fit 설정을 가능한 범위에서 유지하며 새 셀 크기에 맞게 위치를 정상화한다.

레이아웃의 셀보다 이미지가 많으면 남는 이미지를 미배치 목록에 유지하고, 셀이 더 많으면 빈 셀을 표시한다.

빈 셀은 편집 화면에서는 이미지 추가 영역으로 표시하고 최종 결과에서는 배경색 또는 투명 영역으로 렌더링한다.

결과 비율은 1:1, 4:5, 5:4, 3:2, 2:3, 16:9, 9:16과 사용자 지정을 지원하고 결과 픽셀 크기를 별도로 설정하거나 확인할 수 있게 한다.

이미지 사이 간격과 전체 외곽 여백을 각각 설정하고, 콜라주 셀 구분용 테두리는 두께와 색상을 제공한다.

인접 셀 테두리를 각각 이중 렌더링해 가운데 선이 두 배 두꺼워지는 오류가 발생하지 않게 한다.

배경은 흰색, 검정색, 사용자 지정 단색과 투명을 지원하며, 투명 배경은 PNG와 투명도를 지원하는 WebP에서 유지한다.

014에서는 자유 레이어 배치, Masonry, 파노라마 자동 스티칭, Before·After 전용 라벨, 개별 이미지 테두리·둥근 모서리·그림자, 텍스트·스티커·워터마크, AI 자동 디자인과 서버 저장 기능을 포함하지 않는다.

콜라주 미리보기와 최종 Canvas는 동일한 레이아웃 모델과 좌표 계산을 공유하여 미리보기와 다운로드 결과가 달라지지 않게 한다.

미리보기는 축소 이미지와 축소 Canvas를 사용하고 셀 이동·확대 중에는 requestAnimationFrame 등을 사용해 부드럽게 반응하도록 한다.

최종 다운로드 때만 원본 해상도 기준으로 다시 렌더링한다.

파일명이나 비동기 디코딩 완료 순서를 이미지 식별 기준으로 사용하지 않고 고유 ID를 사용한다.

손상 파일이나 미지원 파일 하나 때문에 정상 이미지 전체를 삭제하지 않고 파일별 실패 상태로 격리한다.

매우 큰 결과 픽셀과 여러 고해상도 원본 때문에 브라우저 메모리 한계가 발생할 수 있으므로 결과 Canvas 크기와 총 메모리를 실제 PC·모바일 환경에서 검수하고 안전한 경고·차단 기준을 정한다.

사용자 모르게 결과 해상도를 축소하거나 일부 이미지를 누락하지 않는다.

TOOLBOX 공통 디자인인 화이트·블랙·산토리니 블루 1색과 절제된 고급감을 유지하고 블루는 현재 레이아웃, 선택 셀, 활성 맞춤 방식과 다운로드처럼 핵심 상태에만 사용한다.

PC에서는 큰 콜라주 미리보기를 중심으로 레이아웃·이미지 목록과 셀·전체 설정을 구분하고, 모바일에서는 미리보기 우선 구조와 선택 셀 하단 설정 패널을 사용해 사진 위치 이동과 확대가 실제 터치 환경에서 편하게 작동하도록 한다.

한국어·영어·일본어 UI, 일본어 모바일 줄바꿈, 언어 전환 시 같은 014 페이지 유지, 언어별 URL, H1, 메타 제목, 메타 설명, canonical, hreflang, x-default, WebApplication, FAQPage, BreadcrumbList, sitemap과 robots를 적용한다.

기존 app/sitemap.ts와 app/robots.ts 구조를 유지하고 014의 한국어·영어·일본어 URL만 안전하게 추가한다.

광고는 이미지 선택, 레이아웃 선택, 콜라주 미리보기, 셀 편집, 스타일 설정, 결과 생성과 다운로드 주변에 배치하지 않는다.

공통 자동 검수와 014 전용 검수를 준비하여 레이아웃 셀 좌표, 2·3·4분할, 격자, Cover·Contain 계산, 셀 이미지 pan·zoom, 이미지 교체·교환, 빈 셀·미배치 이미지, 레이아웃 전환, 결과 비율, 간격, 외곽 여백, 테두리, 배경, 투명도, 결과 픽셀, JPG·PNG·WebP 출력과 메모리 정리를 검증한다.

작업 완료 전 기능 축소 여부, 기준 디자인 실제 이식 여부, 기존 검증 기능 영향 여부와 완료라고 말할 실제 근거가 있는지를 확인하는 4대 검증을 수행한다.

자동 검수, 수동 화면 검수, 모바일 셀 편집 검수, 실제 다운로드 결과 검수, 이전 도구 회귀 검수, 빌드, 배포, Search Console URL 검사와 한국어·영어·일본어 URL 색인 요청까지 완료한 뒤에만 웹도구 014를 도장깨기 완료로 처리한다.

불명확한 사항은 임의로 결정하지 않고 실제 프로젝트 코드와 기존 확정 기준을 우선한다.

79\. 핵심 목표
━━━━━━━━━━━━━━━━━━

사용자가 여러 JPG·PNG·WebP 사진을 2·3·4분할과 격자형 레이아웃에 빠르게 배치하고, 각 사진의 비율을 왜곡하지 않은 채 셀 안에서 위치와 확대율을 직접 조정하며, 간격·테두리·배경과 결과 비율을 설정해 고품질 콜라주 한 장으로 다운로드할 수 있는 브라우저 기반 콜라주 도구를 완성한다.

단순히 여러 사진을 정해진 칸에 억지로 넣는 수준에서 끝내지 않는다.

사진이 잘렸을 때 사용자가 직접 위치를 조정하고 전체 보기로 전환할 수 있으며, 레이아웃 변경·셀 교체·빈 셀·미배치 이미지·모바일 편집·투명 배경·고해상도 출력까지 안정적으로 작동하는 완성도 높은 콜라주 도구를 제작한다.
