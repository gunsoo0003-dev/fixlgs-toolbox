# TOOLBOX 일본어 표준 운영

## 파일 역할

- `TOOLBOX_일본어_표준용어집.xlsx`: 사람이 검토·추가하는 마스터 원본
- `TOOLBOX_일본어_UI표기규칙.txt`: 카드명·H1·SEO·버튼·문체·줄바꿈 기준
- `TOOLBOX_일본어_QA체크리스트.txt`: 도구 완료 전 수동 확인표
- `lib/i18n/ja-tool-terms.ts`: 앱과 TypeScript 검수 코드에서 재사용할 표준 용어 데이터
- `lib/i18n/ja-tool-rules.mjs`: Node 검수 스크립트용 금지·혼용 규칙
- `lib/i18n/ja-term-baseline.json`: 기존 001~009에서 이미 존재하는 정비 대상 기준선
- `scripts/check-ja-terms.mjs`: 신규 금지·혼용 표현 검사

## 신규 도구 제작 흐름

1. 제작 전달서에서 한국어 핵심 용어를 추출한다.
2. 엑셀 표준 용어집에서 일본어를 확인한다.
3. 없는 핵심 용어는 임의 번역하지 않고 용어집과 코드 데이터에 먼저 추가한다.
4. 카드명·H1·SEO 제목은 용도에 맞게 분리하되 표준 용어는 유지한다.
5. `npm run check:ja-terms`로 신규 혼용 표현을 검사한다.
6. PC·모바일 일본어 줄바꿈은 화면에서 별도 확인한다.

## 기준선 정책

기존 001~009에서 이미 발견된 비권장 표현은 기준선에 기록되어 있어 현재 빌드를 막지 않는다.
신규 파일이나 수정 과정에서 새 비권장 표현이 추가되면 검수가 실패한다.
기존 기준선 항목을 수정한 뒤에는 `ja-term-baseline.json`에서도 해당 항목을 제거한다.
