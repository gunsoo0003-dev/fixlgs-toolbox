TOOLBOX 일본어 UI 표기 규칙

기본 원칙

-   같은 기능은 전체 TOOLBOX에서 같은 일본어를 사용한다.
-   직역보다 일본 웹서비스에서 자연스러운 표현을 우선한다.
-   카드 표시명, H1, SEO 제목은 목적에 따라 분리할 수 있으나 의미는
    같아야 한다.
-   기존 001~009의 자연스러운 표현은 보존하고, 혼용·비자연 표현만
    표준화한다.

핵심 표준

-   변환기: 変換ツール
-   문서·이미지·디자인 제작기: 作成ツール
-   QR·UUID·코드·랜덤값 생성기: 生成ツール
-   일반 정보 검사기: 確認ツール
-   개발·SEO 유효성 검사: チェッカー 또는 バリデーション
-   리사이즈: サイズ変更
-   블러: ぼかし
-   웹: Webサイト / Web画像 / Web向け
-   파일 내려받기: ダウンロード
-   상태·설정 보관: 保存
-   UI 값 복원: リセット

카드 줄바꿈

-   원칙적으로 1~2줄.
-   ツール, 作成ツール, 確認ツール가 단독 줄에 떨어지지 않게 한다.
-   자동 줄바꿈에 맡기지 않고 의미 단위 줄바꿈 데이터를 둔다.
-   PC와 모바일 일본어를 별도로 확인한다.

문체

-   설명·FAQ·전문가 콘텐츠: です・ます체.
-   버튼: 짧은 동작형.
-   오류: 원인 + 사용자가 할 행동을 명확히 표시.
