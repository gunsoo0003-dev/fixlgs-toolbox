# 010 완료 전 4대 검증

## 검증 1. 간단한 1차 수준으로 축소됐는가
- 판정: 정적 코드 기준 PASS
- 확인 파일: `components/image-mosaic-blur-tool.tsx`, `components/image-mosaic-blur-page.tsx`
- 확인 기능: 사각형, 자유 브러시, 선택, 이동, 크기 변경, 여러 영역, 영역별 효과·강도·색상, 모자이크, 블러, 완전 불투명 단색 가림, 전체 픽셀화, Undo·Redo, 확대·축소·팬, 원본·결과 보기, 영역 표시·숨김, 클립보드, JPG·PNG·WebP 출력, 전체 초기화
- 보완: 브러시 모자이크·블러 마스크 합성, 이동·크기 변경 히스토리 분리, 원본 보기 상태에서도 출력에는 가림 효과가 유지되도록 수정
- 남은 실행 확인: 실제 브라우저 기능검수는 `npm run test:toolbox:010-final`에서 수행

## 검증 2. 기준 디자인을 실제로 이식했는가
- 판정: JSX·CSS 구조 기준 PASS, 실제 화면 검수는 최종 명령에서 확인
- 기준 도구: 001 공통 작업장 + 009 확정 외곽·출력 구조
- 이식 구조: `toolbox-workbench` → 업로드 → `toolbox-workbench-editor-grid` → 미리보기/설정 → 전체 폭 `adjuster-output-card` → 결과 정보
- PC: Playwright 최종검수 대상
- 모바일: Playwright 최종검수 대상
- 다크 모드: Playwright 추가검수 대상
- 차이: 010 고유 캔버스·도구 패널만 내부 기능에 맞게 구성

## 검증 3. 검수기가 제작 전달서 전체를 검증하는가
- 판정: 검수 코드 구성 PASS
- 실행 명령: `npm run test:toolbox:010-final`
- 선제 단계: source → ja-terms → build → common → core → additional → regression → boundary → auto-limit
- 고유검수: 영역 생성·이동·크기 변경·브러시·여러 영역·효과·Undo/Redo·출력·초기화
- 추가검수: 0바이트·MIME/확장자/시그니처 불일치·모바일 다크·언어별 동일 페이지
- 한계검수: 12MP → 15MP → 19.2MP 통과 → 20MP 차단, 16,384px 통과 → 16,385px 차단, 75개 영역 통과 → 76번째 차단
- 결과 생성: 바탕화면 `010_검수결과` 및 ZIP

## 검증 4. 기존 정상 영역이 회귀하지 않았는가
- 판정: 보호 파일 diff PASS
- 비변경 확인: 001 도구, 009 도구, 009 핵심검수·픽셀검수, robots.ts
- 변경 범위: 010 신규 컴포넌트·페이지·검수기, 카테고리/라우팅/사이트맵 최소 등록, 공통 검수 registry의 008~010 누락 등록
- 의도하지 않은 삭제: 없음
- 최종 회귀 확인: `npm run test:toolbox:010-final`

## 최종 완료 게이트
- 빌드 성공 확인이 없으면 완료 금지
- PC 실제 화면 검수 미통과 시 완료 금지
- 태블릿·모바일·터치·화면 회전 검수 미통과 시 완료 금지
- 라이트·다크 실제 화면 검수 미통과 시 완료 금지
- 공통·고유·추가·회귀·경계·자동 한계검수 중 하나라도 실패하면 완료 금지
- 최종 상태는 실패 0, 스킵 0이어야 함
- 자동 한계검수의 최대 통과값·첫 실패값·안전 여유율·권장 운영 한도가 보고서에 기록돼야 함
- 결과 ZIP 생성이 확인돼야 함
