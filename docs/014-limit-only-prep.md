## 보수적 서비스 유효상한 후보

### 1. 선택 파일 개수
- 후보값: **12개**
- 테스트값: 9 / 11 / 12 / 13
- 일반 사용자 충분성: 최대 9셀 사용에 교체용 대기 이미지 3장까지 확보 가능.
- PC 안정성 고려: 썸네일·Bitmap·상태 객체 수를 과도하게 늘리지 않음.
- 모바일 안정성 고려: 20장 이상 대기 목록보다 메모리·스크롤 부담이 낮음.
- 처리시간 고려: 최초 디코딩·썸네일 생성 시간을 짧게 유지하기 유리.
- 메모리 부담 고려: 다중 고해상도 원본 동시 유지 위험을 보수적으로 낮춤.
- 그 이상 추가 사용자 효용: 낮음. 014는 최대 9셀 콜라주 도구이므로 13장 이상은 전문/대량 선택 성격이 강함.
- 전문 사용자 영역: 13장 초과 대량 선택.
- 확신도: **높음**

### 2. 개별 파일 크기
- 후보값: **15 MiB**
- 테스트값: 5 / 14 / 15 / 16 MiB
- 일반 사용자 충분성: 일반 스마트폰 JPG/PNG/WebP와 상당수 고품질 원본에 충분.
- PC 안정성 고려: 25MiB급 파일보다 디코딩 실패·메모리 급증 가능성을 낮춤.
- 모바일 안정성 고려: 저사양·다중 탭 환경에서도 안전마진 확보.
- 처리시간 고려: 대형 PNG/WebP 디코딩 지연 완화.
- 메모리 부담 고려: 파일 압축용량보다 디코딩 후 픽셀 메모리가 커지는 점을 고려.
- 그 이상 추가 사용자 효용: 일반 콜라주 용도에서는 낮음.
- 전문 사용자 영역: 15MiB 초과 대형 원본/전문 촬영 파일.
- 확신도: **보통**

### 3. 총 선택 파일 용량
- 후보값: **80 MiB**
- 테스트값: 45 / 75 / 80 / 85 MiB
- 일반 사용자 충분성: 12개 후보 기준 평균 약 6.7MiB로 일반 사진 묶음에 충분.
- PC 안정성 고려: 150MiB보다 브라우저 메모리 압박을 크게 줄임.
- 모바일 안정성 고려: 다중 탭·저사양 환경에서 안전마진 확보.
- 처리시간 고려: 업로드 전송은 없지만 로컬 디코딩·썸네일 생성 시간을 줄임.
- 메모리 부담 고려: 압축 파일 용량과 실제 디코딩 메모리는 별개이므로 보수적으로 설정.
- 그 이상 추가 사용자 효용: 낮음.
- 전문 사용자 영역: 80MiB 초과 대형 이미지 묶음.
- 확신도: **보통**

### 4. 원본 이미지 해상도
- 후보값: **24 MP**
- 테스트값: 12 / 23 / 24 / 25 MP
- 일반 사용자 충분성: 일반 스마트폰 12MP~24MP 사용 범위를 충분히 포괄.
- PC 안정성 고려: 40MP급 원본보다 디코딩 메모리 부담 감소.
- 모바일 안정성 고려: 24MP도 충분히 큰 원본이므로 그 이상은 보수적으로 제외.
- 처리시간 고려: Cover/Contain 미리보기와 최종 렌더 비용 감소.
- 메모리 부담 고려: 24MP RGBA 한 장도 디코딩 시 약 96MB 수준의 원시 메모리가 필요할 수 있음.
- 그 이상 추가 사용자 효용: 일반 웹/SNS 콜라주에서는 매우 낮음.
- 전문 사용자 영역: 24MP 초과 고해상도 카메라/초고해상도 촬영 파일.
- 확신도: **보통**

### 5. 결과 이미지 최대 한 변
- 후보값: **3000 px**
- 테스트값: 1600 / 2999 / 3000 / 3001
- 일반 사용자 충분성: SNS·블로그·웹 게시와 일반적인 고화질 저장에 충분.
- PC 안정성 고려: 4096px보다 Canvas·인코딩 부담 감소.
- 모바일 안정성 고려: 9MP급 최종 Canvas로 안전마진을 더 확보.
- 처리시간 고려: 최종 렌더·PNG/WebP 인코딩 시간이 짧아짐.
- 메모리 부담 고려: 3000×3000 RGBA는 약 36MB 원시 Canvas 메모리로 4096² 약 67MB보다 부담이 낮음.
- 그 이상 추가 사용자 효용: 일반 웹 콜라주에서는 낮음.
- 전문 사용자 영역: 3000px 초과 대형 인쇄·초고해상도 출력.
- 확신도: **높음**

### 6. 결과 총 픽셀
- 후보값: **9,000,000 px**
- 테스트값: 4MP / 8.9MP / 9MP / 9.1MP
- 일반 사용자 충분성: 3000×3000 정사각형 기준.
- PC 안정성 고려: 일반 브라우저에서 과도한 Canvas를 피하는 보수적 범위.
- 모바일 안정성 고려: 16.8MP보다 메모리 부담이 크게 낮음.
- 처리시간 고려: 최종 렌더·인코딩 속도에 유리.
- 메모리 부담 고려: 최종 Canvas만 약 36MB RGBA, 여기에 원본 Bitmap이 추가됨.
- 그 이상 추가 사용자 효용: 일반 사용자에게 제한적.
- 전문 사용자 영역: 9MP 초과 대형 출력.
- 확신도: **보통**
