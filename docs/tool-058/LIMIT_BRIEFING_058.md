# TOOL058 SERVICE LIMIT BRIEFING
- Absolute input recommendation: `1e15`.
- Display precision: `0..8` digits.
- Data representative results: max `6`.
- Data notation modes: exactly `decimal 1000` and `binary 1024`.
- Cooking units: exactly `cup`, `tbsp`, `tsp`, `mL` for first release.
- Negative data/cooking values: blocked.
- Zero: allowed.
- Internal conversion is independent of display rounding.
