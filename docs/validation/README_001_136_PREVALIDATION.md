# TOOLBOX 001~136 선제 검수 체계

이 문서는 136개 도구의 실제 기능 코드를 미리 추측해 완성하는 문서가 아니다. 도장깨기 목록에서 확정된 도구명과 기본 기능을 기준으로 공통검수, 유형별 검수, 예상 고유검수, 자동 한계검수 대상을 미리 등록하여 다음 제작 때 누락을 줄이는 실행 기준이다.

## 생성 범위

- 도구 계획: 136개
- 카테고리: 11개
- 검수 유형: 62개
- 전체 공통검수: 35개
- 유형별 검수 프로필: 10개

## 사용 순서

1. 다음 도구 번호를 `tool-001-136-validation-plan.json`에서 찾는다.
2. 전체 공통검수를 기본으로 적용한다.
3. `profiles`에 연결된 유형별 검수를 조립한다.
4. `features`를 최종 제작 전달서와 비교해 고유검수를 추가한다.
5. 실제 UI가 만들어지기 전에 data-testid, 오류 문구, 상태값, 출력 형식을 확정한다.
6. 기능 구현 후에는 검수 항목을 약화하지 않고 실제 코드와 선택자를 연결한다.
7. 도구 완료 시 새 실패 패턴을 공통 또는 유형별 프로필에 추가한다.

## 금지

- 아직 없는 UI 선택자를 임의 확정하지 않는다.
- 예상 검수 명세를 실제 통과 검수로 표시하지 않는다.
- 기존 001~010 통과 검수기를 이 계획 파일로 대체하지 않는다.
- 한계값을 다른 도구에서 복사해 확정하지 않는다.

## 완료 게이트

현재 도구 완료 전 다음을 확인한다.

- 이번 도구에서 발견된 공통 검수 규칙 누적 완료
- 다음 도구의 선제 검수 조립 완료
- 136개 계획 카탈로그와 실제 최종 전달서의 차이 기록 완료
