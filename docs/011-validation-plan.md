# 011 선제 검수 계획

도구 유형: canvas-image-compose.

필수 선제 검수: 입력 디코딩/JPG·PNG·WebP/투명도/EXIF, 전체·방향별 여백, 값 연결, 정사각형·비율·사용자 크기, contain 배치, 단색·투명·블러 렌더링, 이미지 크기·정렬·드래그, Undo/Redo, 원본·결과 보기, 줌·화면맞춤, JPG·PNG·WebP 출력 재디코딩, Object URL 정리, PC·태블릿·모바일, 한국어·영어·일본어, 라이트·다크, SEO·sitemap·robots·기존 001~010 회귀.

한계검수는 구현 후 실제 최대 통과값과 첫 실패값을 산출한다. 후보값을 운영 한계로 확정하지 않는다. 결과 픽셀 수, 최대 한 변, 입력 파일 용량, 블러 임시 캔버스 메모리, 히스토리 단계, 렌더링 시간을 별도로 기록한다.
