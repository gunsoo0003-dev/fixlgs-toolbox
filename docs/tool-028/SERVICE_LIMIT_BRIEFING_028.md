## 판단 근거
- 전달서 자체가 모바일 메모리와 일반 사용자 범위를 고려해 낮은 후보를 우선 검토하도록 지시한다.
- PDF 병합은 원본 페이지 객체를 복사하므로 페이지 rasterize 자체보다 입력 PDF 파싱·미리보기 렌더·브라우저 메모리가 실제 안정성 병목이 될 수 있다.
- 보조작업장에서는 실제 PC/모바일 limit-only를 수행할 런타임 환경이 없으므로 더 높은 후보 B를 안전하다고 확정할 근거가 없다.
