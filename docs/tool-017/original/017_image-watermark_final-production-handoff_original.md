━━━━━━━━━━━━━━━━━━

이 도구는 사용자가 자신의 텍스트 또는 로고를 이미지 위에 워터마크로 표시하고, 필요하면 같은 설정을 여러 이미지에 한꺼번에 적용하는 도구다.

대표 사용 목적:

- 사진에 저작권 문구 표시
- 작가명·회사명 표시
- 웹사이트 주소 표시
- 쇼핑몰 상품 사진에 상호 표시
- 포트폴리오 이미지에 이름 표시
- 고객 전달용 시안에 SAMPLE 표시
- 미확정 이미지에 DRAFT 표시
- 사진에 로고 삽입
- 판매 이미지에 브랜드 로고 표시
- 여러 상품 이미지에 동일 로고 일괄 삽입
- 여러 사진에 같은 저작권 문구 일괄 적용
- 복사 방지를 위해 전체 이미지에 반복 워터마크 배치
- 반투명 대각선 워터마크 적용

대표 작업 흐름:

이미지 한 장 또는 여러 장 선택
→ 텍스트 또는 로고 워터마크 선택
→ 내용·크기·위치·투명도 설정
→ 필요하면 회전 설정
→ 필요하면 반복 워터마크 활성화
→ 대표 이미지 미리보기
→ 다른 이미지에도 동일 설정 확인
→ 일괄 적용
→ 개별 다운로드 또는 ZIP 다운로드

6\. 실제 사용자 요구
━━━━━━━━━━━━━━━━━━

대표 요구:

- 상품 사진 수십 장에 같은 로고를 한 번에 넣고 싶음
- 사진마다 하나씩 편집하고 싶지 않음
- 오른쪽 아래 같은 위치에 항상 같은 워터마크를 넣고 싶음
- 크기가 다른 이미지에서도 로고가 비슷한 비율로 보였으면 좋겠음
- 로고 투명도를 쉽게 조절하고 싶음
- 텍스트 워터마크를 대각선으로 반복하고 싶음
- 사진 전체에 복사 방지 표시를 넣고 싶음
- 워터마크가 사진 바깥으로 잘리지 않았으면 좋겠음
- PNG 로고 투명 배경을 유지하고 싶음
- 여러 결과를 ZIP 하나로 받고 싶음
- 원본 파일명과 연결되는 결과명을 유지하고 싶음
- 서버 업로드 없이 처리하고 싶음

7\. 반복되는 사용자 불만
━━━━━━━━━━━━━━━━━━

- 이미지마다 워터마크 크기가 다르게 보임
- 큰 사진과 작은 사진에 같은 px 크기를 적용해 비율이 달라짐
- 워터마크가 사진 끝에서 잘림
- 모바일에서 위치 조절이 어려움
- 투명 PNG 로고 배경이 검정 또는 흰색으로 변함
- 워터마크가 너무 흐리거나 너무 진함
- 반복 워터마크 간격이 일정하지 않음
- 대각선 반복 시 모서리에 빈 영역이 생김
- 일괄 처리 중 한 장 오류 때문에 전체 작업 실패
- ZIP에 파일이 누락됨
- 동일 파일명 때문에 결과가 덮어써짐
- 결과 파일명이 알아보기 어려움
- 처리 순서가 업로드 순서와 달라짐
- 고해상도 이미지가 많으면 브라우저가 멈춤
- 결과 저장 후 사진 화질이 예상보다 낮음
- EXIF 방향 때문에 워터마크 위치가 회전되어 보임
- 반복 워터마크가 미리보기와 출력에서 다른 위치에 나타남

017은 이러한 문제를 핵심 검수 기준으로 삼는다.

87\. 주의사항
━━━━━━━━━━━━━━━━━━

- 원본 파일은 수정되지 않는다.
- 모든 처리는 현재 브라우저에서 수행된다.
- 여러 이미지에는 상대 위치와 상대 크기를 기준으로 같은 워터마크 설정이 적용된다.
- 이미지 비율이 크게 다르면 각 대표 이미지를 클릭해 결과를 확인하는 것을 권장한다.
- 작은 로고를 크게 확대하면 흐리게 보일 수 있다.
- 투명 PNG 로고는 원본 투명도를 유지한다.
- 반복 워터마크는 사진 전체를 가릴 수 있으므로 투명도와 밀도를 확인한다.
- 매우 많은 고해상도 파일을 동시에 처리하면 브라우저 메모리가 부족할 수 있다.
- 일부 파일 처리에 실패해도 정상 결과는 유지된다.
- JPG 출력은 투명도를 지원하지 않는다.
- 워터마크는 출처·소유권 표시와 무단 사용 억제에 도움을 줄 수 있지만 제거 불가능성을 보장하지 않는다.
- 이 도구는 기존 이미지에 있는 타인의 워터마크를 제거하는 기능을 제공하지 않는다.

Q1. 여러 사진에 같은 워터마크를 한 번에 넣을 수 있나요?

예. 워터마크를 한 번 설정한 뒤 선택한 여러 이미지에 같은 상대 크기와 위치로 일괄 적용할 수 있습니다.

Q2. 텍스트 워터마크를 넣을 수 있나요?

예. 문구, 글꼴, 크기, 색상, 투명도와 위치를 설정할 수 있습니다.

Q3. 회사 로고도 사용할 수 있나요?

예. PNG·JPG·WebP 로고 이미지를 워터마크로 사용할 수 있습니다.

Q4. 투명 PNG 로고도 지원하나요?

예. PNG 로고의 투명 영역을 유지해 이미지 위에 합성할 수 있습니다.

Q5. 사진 전체에 워터마크를 반복할 수 있나요?

예. 반복 워터마크를 켜고 크기, 투명도, 각도와 간격을 조절할 수 있습니다.

Q6. 워터마크 위치를 직접 옮길 수 있나요?

예. 9방향 위치를 선택하거나 대표 이미지 위에서 직접 드래그해 이동할 수 있습니다.

Q7. 사진 크기가 서로 달라도 같은 크기로 보이나요?

기본적으로 이미지 크기에 대한 상대 비율을 사용해 비슷한 시각적 크기로 적용합니다.

Q8. 원본 이미지 크기가 바뀌나요?

기본적으로 원본 픽셀 크기를 유지한 채 워터마크만 합성합니다.

Q9. 결과를 한 번에 다운로드할 수 있나요?

예. 여러 결과를 ZIP 파일로 묶어 다운로드할 수 있습니다.

Q10. 일부 이미지가 실패하면 처음부터 다시 해야 하나요?

아니요. 정상 처리된 결과는 유지하고 실패한 파일만 다시 처리할 수 있도록 합니다.

Q11. 이미지는 서버로 업로드되나요?

아니요. 이미지, 로고와 텍스트는 현재 브라우저 안에서 처리됩니다.

Q12. 이미지에 이미 있는 워터마크를 지울 수 있나요?

아니요. 017은 워터마크를 추가하는 도구이며 기존 워터마크 제거 기능은 제공하지 않습니다.

각 파일은 파일명이 아니라 내부 고유 ID로 관리하고 동일 파일명과 동일 파일 반복 추가를 정상 지원한다.

텍스트 워터마크는 문구, 글꼴, 글자 크기, 굵게, 색상, 투명도, 외곽선과 그림자를 제공한다.

한국어·영어·일본어 글꼴은 016에서 검증된 font fallback 구조가 있다면 우선 재사용한다.

로고 워터마크는 PNG·JPG·WebP를 지원하고 특히 투명 PNG alpha를 정확하게 유지한다.

로고 가로세로 비율을 강제로 변형하지 않는다.

워터마크 위치는 왼쪽 위, 위 가운데, 오른쪽 위, 왼쪽 가운데, 가운데, 오른쪽 가운데, 왼쪽 아래, 아래 가운데, 오른쪽 아래의 9방향 프리셋을 제공하고 대표 이미지 위에서 직접 드래그해 사용자 지정 위치로 옮길 수 있게 한다.

다중 이미지 일괄 처리에서 절대 픽셀 위치와 크기를 그대로 복사하지 않는다.

워터마크 위치는 이미지 너비·높이 기준 normalized coordinate로 관리하고 워터마크 크기는 이미지 크기 대비 상대 비율로 관리하여 가로·세로·정사각형 및 서로 다른 해상도의 이미지에서도 유사한 시각적 위치와 크기로 적용되게 한다.

대표 이미지를 파일 목록에서 자유롭게 변경해 서로 다른 비율의 이미지에서 워터마크가 어떻게 표시되는지 확인할 수 있게 한다.

대표 이미지 변경은 워터마크 설정 자체를 변경하지 않는다.

반복 워터마크는 텍스트와 로고를 대상으로 격자 및 대각선 반복을 지원하고 투명도, 각도, 가로 간격, 세로 간격 또는 밀도를 조절할 수 있게 한다.

회전된 반복 패턴은 실제 이미지 영역보다 넓게 반복 좌표를 계산하여 네 모서리에 큰 빈 영역이 생기지 않도록 하고 최종 Canvas에서 이미지 영역으로 clip한다.

반복 워터마크 개수가 많아질 경우 동일 텍스트나 로고를 위치마다 처음부터 렌더링하지 않고 작은 offscreen tile을 만들어 반복 draw하는 최적화를 검토한다.

텍스트와 로고를 동시에 사용하는 수요가 있으므로 브라우저 성능과 UI 복잡성에 문제가 없다면 최대 2개의 제한된 워터마크 레이어를 지원한다.

전문 그래픽 레이어 편집기로 확대하지 않는다.

017에서는 기존 워터마크 제거, AI 제거, 객체 제거, invisible watermark, steganography, C2PA, 암호학적 워터마크, PDF·동영상·GIF 워터마크, 자유 이미지 편집, OCR, 스티커와 전문 디자인 기능을 포함하지 않는다.
