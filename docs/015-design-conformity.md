# 015 디자인 정합성 사전 확인

## 기준
- 기본 기준: 001 JPG·PNG·WebP 이미지 변환기
- 유사 구조 기준: 013 이미지 합치기
- 3차 디자인 지시서에 따라 차이는 정상 차이 / 확정 기준 불일치 / 판단 불가로 구분한다.

## 코드 기준으로 확인한 공통 디자인
- 공통 TOOLBOX 페이지 shell 및 workbench 계열 클래스 재사용
- Primary Action: 검정 배경 + 흰 글씨
- 선택/활성 상태: 산토리니 블루
- 큰 이미지 작업영역과 설정영역 분리
- HOW TO USE: 5단계 3열×2행, 중앙 세로선 2개, 좌우 외곽 세로선 제거
- H1 의미 단위 줄바꿈 적용
- NEXT WORK / FAQ / EXPERT POST 기존 공통 구조 재사용
- 일본어 긴 버튼 문구는 의미 단위 줄바꿈 가능하도록 전용 처리
- 공통 CSS 수정 없음

## 정상 차이로 유지
- 015는 정확히 두 슬롯을 가지므로 001/013의 단일·다중 파일 목록 구조와 동일하게 만들지 않음.
- 비교 결과가 핵심이므로 PC에서 큰 비교 Canvas + 우측 설정 패널 구조를 유지.
- 모바일에서는 비교 미리보기 우선 후 설정이 내려오는 전용 흐름을 유지.

## 확정 기준 불일치로 수정한 항목
- 실제 UI 번호는 내부 번호 `015`가 아니라 사용자 표시값 `15`로 사용.
- 사용 방법은 기존 확정 5단계 시각 구조를 적용하고 원 기획 10단계 내용을 5개 단계 안에 축약 삭제 없이 결합.
- Primary Action을 블루 버튼으로 만들지 않고 검정/흰색 계열 유지.

## 판단 불가 / 주작업장 확인 필요
현재 보조작업장 런타임에서 npm registry가 `@playwright/test`, `@types/node`를 404로 반환하여 실제 Next.js 렌더를 띄울 수 없음.
따라서 아래는 코드 기준 준비만 완료했으며 실제 화면 최종 판정은 주작업장에서 한다.
- PC 실제 픽셀 간격/패딩/높이
- 모바일 실제 줄바꿈/버튼 높이
- 라이트/다크 실제 대비
- Canvas와 설정 패널 실제 밀도
- 실제 drag-over/Pointer 조작 시각상태

## 기존 완료 영역 수정
없음. 공통 CSS와 001~013 완료 도구는 수정하지 않았다.
