# TOOLBOX 016 서비스 유효상한 후보 및 주작업장 확정

보조작업장 후보는 기술적 여유를 넓게 잡아 전달됐고, 주작업장에서는 일반 PC·노트북·스마트폰·브라우저의 일반 사용자와 중간 수준 라이트 사용자 기준으로 다시 검토했다.

보조작업장 후보:
- 입력 이미지: 1장, 25MB 후보
- 이미지 총 픽셀: 40,000,000px 후보
- 이미지 한 변: 10,000px 후보
- 텍스트 레이어: 30개 후보
- 레이어당 입력 문자: 5,000자 후보
- 히스토리: 40단계 후보

주작업장 최종 서비스 상한:
- 입력 이미지: 1장
- 파일당 최대: 15 MiB
- 이미지 총 픽셀: 12,000,000px
- 이미지 한 변: 6,000px
- 텍스트 레이어: 20개
- 레이어당 입력 문자: 2,000자
- 히스토리: 30단계
- 출력: 입력 원본 해상도 유지. 따라서 12MP / 6,000px 상한을 그대로 적용

판단:
원본 해상도 Canvas와 텍스트 효과를 동시에 사용하는 016 특성상 20MP 이상은 일반 스마트폰에서 메모리 부담이 커질 수 있다.
12MP·6,000px는 일반 사진 편집에는 충분하며, 더 높은 값의 추가 효용은 전문 사용자 영역에 가까워진다.
20개 레이어·2,000자·Undo 30단계도 제목·본문·날짜·위치·여러 설명을 넣는 일반 사용자 흐름에 충분하다.

전문·하드코어 제외 영역:
수천 줄 문서, 수백 텍스트 레이어, 초고해상도 전문 인쇄 원본, 사용자 폰트/복잡한 transform, 대량 이미지 일괄 적용.
