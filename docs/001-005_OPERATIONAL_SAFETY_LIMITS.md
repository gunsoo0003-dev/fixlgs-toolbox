# TOOLBOX 001~005 운영 안전선 확정 기록

001~005의 기존 제한값은 단계별 실제 처리와 경계 차단 검수 통과 결과를 기준으로 운영 안전선으로 확정한다. 이 수치는 다른 도구에 일괄 적용하지 않는다.

## 001 JPG·PNG·WebP 이미지 변환

- 최대 파일 수: 10개
- 파일당 최대 용량: 20MB
- 전체 최대 용량: 60MB
- 이미지당 최대 픽셀: 40,000,000px
- 실제 처리 통과: 4MP, 12MP, 24MP PNG, 36MP WebP, 40MP JPG
- 모바일 viewport 통과: 12MP

## 002 HEIC·AVIF 이미지 변환

- 최대 파일 수: 10개
- 파일당 최대 용량: 10MB
- 전체 최대 용량: 50MB
- 이미지당 최대 픽셀: 40,000,000px
- 실제 처리 통과: JPG·PNG → AVIF 4MP, 12MP, 24MP, 32MP, 40MP
- 모바일 viewport 통과: 8MP
- 주의: 실제 HEIC 디코딩 한계는 HEIC 원본 샘플이 확보되면 별도 재검증한다. 현재 안전선은 JPG·PNG→AVIF 인코딩과 코드 경계를 기준으로 확정한다.

## 003 SVG·BMP·TIFF 이미지 변환

- 최대 파일 수: 10개
- 파일당 최대 용량: 20MB
- 전체 최대 용량: 60MB
- 파일/출력당 최대 픽셀: 40,000,000px
- TIFF 선택 페이지 전체 최대 픽셀: 80,000,000px
- 실제 처리 통과: SVG 래스터 변환 4MP, 12MP, 24MP, 36MP, 40MP
- 모바일 viewport 통과: 12MP
- 주의: 다중 페이지 TIFF 실제 디코딩 한계는 TIFF 샘플 확보 후 별도 재검증한다. 80MP는 보수적 브라우저 보호선과 코드 경계로 유지한다.

## 004 이미지 압축

- 최대 파일 수: 10개
- 파일당 최대 용량: 15MB
- 전체 최대 용량: 50MB
- 이미지당 최대 픽셀: 30,000,000px
- 전체 최대 픽셀: 80,000,000px
- 실제 처리 통과: 4MP, 12MP, 24MP, 30MP
- 모바일 viewport 통과: 12MP

## 005 목표 용량 이미지 압축

- 최대 파일 수: 10개
- 파일당 최대 용량: 15MB
- 전체 최대 용량: 50MB
- 이미지당 최대 픽셀: 30,000,000px
- 전체 최대 픽셀: 80,000,000px
- 품질 탐색 최대 반복: 9회
- 실제 처리 통과: 4MP/500KB, 12MP/500KB, 24MP/300KB(크기 조정), 30MP/200KB(크기 조정)
- 모바일 viewport 통과: 12MP/500KB

## 보호 규칙

- 검수 완료된 제한값·테스트 샘플·선택자·통과 조건은 후속 도구 제작의 참고 기준이며 임의 수정 대상이 아니다.
- 공통화나 리팩터링으로 변경이 불가피하면 영향 범위를 먼저 확인하고, 변경 후 해당 도구 한계·경계검수를 다시 실행한다.
- 모바일 항목은 실제 모바일 기기 메모리 한계가 아니라 Playwright 모바일 viewport 검수다. 실제 기기 문제가 확인되면 별도 보수 조정한다.
